# Instrument samples

Served from this folder so the app never sends a listener to another site, and so a played
instrument keeps working offline.

- `salamander/`: Salamander Grand Piano V3 by Alexander Holm, as packaged by Tone.js
  (https://tonejs.github.io/audio/salamander/). Licence: CC BY 3.0
  (https://creativecommons.org/licenses/by/3.0/).
- Every other folder: tonejs-instruments by Nicholas Brosowsky
  (https://github.com/nbrosowsky/tonejs-instruments), samples licensed CC BY 3.0
  (https://creativecommons.org/licenses/by/3.0/).

Files are unchanged copies. Only the pitches `js/audio.js` asks for are included.
